Comment Signal a été construit avec un agent de code (Claude Code), une étape après l'autre.
`PLAN.md` donne l'ordre des étapes et la checklist de chacune ; `BUILD_LOG.md` tient le journal de chaque session (durée, coût, choix, dettes) ; `REVIEW_NOTES.md` est la revue faite avant l'évaluation.
Ces fichiers décrivent la méthode ; le produit est décrit dans `SPEC.md`, `docs/ARCHITECTURE.md` et `docs/DECISIONS.md`.
